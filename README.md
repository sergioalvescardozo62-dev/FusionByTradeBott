
# FusionByTradeBott

Bot de trading em Python para BTC/USDT.

- Estratégia de médias móveis.
- Simulação de compras e vendas.
- Carteira fictícia de 1000 USDT.
- Testes automáticos no GitHub Actions.

IMPORTANTE: esta versão funciona apenas em modo de simulação.
Não realiza operações financeiras reais.
